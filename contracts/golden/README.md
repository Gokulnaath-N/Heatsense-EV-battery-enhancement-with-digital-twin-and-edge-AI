# contracts/golden

## Purpose
Contains immutable golden telemetry test vectors establishing the single source of truth for cross-language wire protocol compatibility between the ESP32 firmware (C++) and the Python host backend.

## Goal served
G1 (Byte-Exact Ambiguity-Free Spec) and G3 (One Set of Test Vectors for Two Languages). Proves that both Python and C++ decoders parse valid frames identically and reject malformed frames with the exact same error classifications.

## Golden Files
1. `frames.jsonl`: Rich JSON Lines format containing vector ID, human description, chunk sequences (`chunks_hex`), expected events, and expected diagnostic counters. Consumed by Python pytest suites (`host/tests/contract/test_golden_frames.py`).
2. `frames.txt`: Compact token-delimited line format (`<id>|<chunks_hex>|<events>`). Consumed by embedded C++ Unity test runners without requiring a JSON parser.

## Independence Invariant
These vectors are generated by `scripts/gen_golden.py`. That generator is strictly independent of the `heatsense` Python package: it contains an isolated bitwise shift-and-XOR implementation of CRC-16/CCITT-FALSE and asserts the check value `0x29B1` on `"123456789"` before emitting vectors.

## How to Regenerate Vectors
```bash
python scripts/gen_golden.py
```
Regeneration is deterministic. `host/tests/contract/test_golden_frames.py` asserts that committed files match a fresh generation byte for byte.
