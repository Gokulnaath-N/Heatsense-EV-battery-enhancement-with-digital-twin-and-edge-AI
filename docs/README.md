# HeatSense Documentation Hub

## Purpose
Acts as the central documentation catalog for HeatSense, defining terminology, claims policies, safety limits, architectural blueprints, and protocol specifications.

## Contents
- `architecture/`: System overview, layer dependencies, and architecture decision records.
- `api/`: Shared contracts and REST/WebSocket API schemas.
- `data/`: Dataset inspection checklists and data dictionary specifications.
- `research/`: Experiment protocols, Model A vs B benchmark design, and causal testing rules.
- `deployment/`: Local Windows setup and environment guidelines.
- `development/`: Phase 1 milestone checklists and testing instructions.
