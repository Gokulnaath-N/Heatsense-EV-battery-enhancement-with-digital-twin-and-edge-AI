# Local Windows development

Recommended initial root:

`D:\Professional Projects\Digital_twin_project\heatsense-battery-digital-twin`

Keep the existing dataset as a sibling folder:

`D:\Professional Projects\Digital_twin_project\Datasets\cleaned_dataset`

Set `HEATSENSE_DATASET_ROOT` in a local `.env` file to the dataset path (forward slashes are acceptable in the environment value). Do not commit `.env`.

Use Windows Command Prompt (cmd), not Bash. The exact environment creation/install commands should be chosen after checking the installed Python and Node versions.
