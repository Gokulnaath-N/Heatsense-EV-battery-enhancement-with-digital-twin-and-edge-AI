# HeatSense Architecture Open Questions Register

Status: Draft for review
Last updated: 2026-10-26

## Purpose

This register consolidates all open architectural, hardware, algorithmic, and governance questions across HeatSense. It provides transparent visibility into technical uncertainties, candidate options, recommended engineering defaults, assigned owners, and downstream blocked prompts.

## Guidelines for Resolving Open Questions

1. When a decision is reached by the assigned owner, the corresponding ADR or specification must be updated.
2. The question status transitions from `Open` to `Resolved` with a date and a link to the resolving ADR or commit.
3. No prompt may begin implementation if any question blocking it remains `Open`.
